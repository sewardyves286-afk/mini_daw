# mini_daw 
mini_daw is a litghtweigt Digital Audio workstation (DAW) built in python.
## projet Goal

The goal of this project is to progressively build a modular audio from scratch, including:
'''
- Audio playback
- Audio recording
- Waveform visualization
- Real-time audio processing
- Modular architecture
'''
This project is inspired by modern DAWs like Ableton live and Fl studio, but focuses on understanding and  implement the core fundamentals step by step
## projetc structure

mini_daw/
___engine.py # Audio engine
___recorder.py # Recording module
___main.py # Application entry point
___gu.py # graphical interface
